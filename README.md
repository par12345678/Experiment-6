# Java Servlet 

## Description
This practical demonstrates how Java Servlets process HTTP requests and generate responses on a web server.

## Technologies Used
- Java
- Servlets
- Apache Tomcat
- Maven

## Requirements
- JDK
- Apache Maven
- Compatible Apache Tomcat version

## How to Run
1. Open the project folder containing `pom.xml`.
2. Build the project:
   ```bash
   mvn clean package
   ```
3. Copy the generated WAR file from `target` to Tomcat's `webapps` folder.
4. Start Tomcat.
5. Open the application using its deployed context path.

## Learning Outcome
Understand servlet lifecycle basics, HTTP requests, and web application deployment.
